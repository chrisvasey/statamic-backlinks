## [1.0.0] - 2025-01-18

### Added

- Wiki-link syntax support (`[[Page Title]]` and `[[Page Title|Display Text]]`)
- Automatic backlink tracking between entries
- Missing link detection with visual styling
- Page creation from missing wiki-links
- Dashboard widget for backlink activity
- Entry sidebar showing backlinks
- `backlinks` Antlers tag for template display
- `wiki_links` modifier for rendering wiki-links
- `backlinks:rebuild` command for index rebuilding
- Configurable collections, fields, and CSS classes
